Fundamento Matemático y Econométrico

Esta aplicación utiliza formulaciones analíticas exactas y contrastes econométricos institucionales, evitando aproximaciones simplistas o supuestos no contrastados.

1. Modelo Black-76 (Futuros Oficial CME/ICE)

Fischer Black (1976) adaptó Black-Scholes para contratos de futuros donde no hay desembolso de capital al inicio:

d₁ = [ln(F / K) + 0.5 σ² T] / (σ √T)
d₂ = d₁ - σ √T
C = e⁻ʳᵀ [ F Φ(d₁) - K Φ(d₂) ]
P = e⁻ʳᵀ [ K Φ(-d₂) - F Φ(-d₁) ]

2. Black-Scholes-Merton (1973 con Carry q)

Modelo generalizado con costo de almacenamiento o conveniencia continuo q:

d₁ = [ln(S / K) + (r - q + 0.5 σ²) T] / (σ √T)
d₂ = d₁ - σ √T
C = S e⁻ᵍᵀ Φ(d₁) - K e⁻ʳᵀ Φ(d₂)
P = K e⁻ʳᵀ Φ(-d₂) - S e⁻ᵍᵀ Φ(-d₁)

3. Estimadores Econométricos de Volatilidad

Capturan el rango intradiario y superan la ineficiencia de Close-to-Close:

Parkinson (1980): σ² = (1 / 4 ln 2 N) Σ [ln(Hᵢ / Lᵢ)]²
Garman-Klass (1980): σ² = (1/N) Σ [ 0.5 ln(H/L)² - (2 ln 2 - 1) ln(C/O)² ]

4. Contrastes de Diagnóstico de Residuos

Verifican empíricamente si se cumplen los supuestos de martingala y distribución lognormal:

Jarque-Bera: JB = (N/6) [ S² + 0.25 (K - 3)² ] ~ χ²(2)
Durbin-Watson: DW = Σ(eₜ - eₜ₋₁)² / Σ eₜ² (Autocorrelación serial)
Sesgo Medio (Bias): ē = (1/N) Σ(Realizado - Estimado)
